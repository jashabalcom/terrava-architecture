# ADR-0000: Template

**Status:** Proposed | Accepted | Superseded by ADR-NNNN
**Date:** YYYY-MM
**Scope:** Which part of the system this touches

## Context

What situation forced a decision. Constraints that were real at the time: budget, team size,
compliance, deadline, existing commitments. Write this so it still makes sense to someone who
wasn't there — the constraints are the whole story.

## Options considered

### Option A — name

What it is. Why it lost (or won).

### Option B — name

What it is. Why it lost (or won).

## Decision

The option chosen, stated in one sentence, plus the deciding factor.

## Consequences

**What got better**

- ...

**What got worse**

- ...

The second list must not be empty. If a decision has no downside, it wasn't a decision.

## Revisit when

The concrete, observable signal that would make this decision wrong. A number, an event, or a
threshold — not "if requirements change."
